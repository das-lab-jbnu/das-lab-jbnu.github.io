das.jbnu.ac.kr 취약점 조치 결과보고서

1. SRI(Subresource Integrity) 미적용
- 점검 항목: 외부 리소스 무결성 검증 적용 여부
- 취약점 조치: 외부 Google Fonts 사용 제거 완료
- 처리 방법: 각 HTML 페이지에서 fonts.googleapis.com 외부 폰트 링크를 삭제하고 로컬 CSS 기준으로 페이지 구성
- 적용 페이지: /, /projects.html, /patents.html, /team.html, /publications.html, /gallery.html

2. Content-Security-Policy 헤더 누락
- 점검 항목: CSP 보안 정책 적용 여부
- 취약점 조치: HTML meta 태그 기반 CSP 정책 추가 완료
- 처리 방법: 각 HTML 페이지 head 영역에 Content-Security-Policy meta 태그 추가
- 적용 페이지: /, /projects.html, /patents.html, /team.html, /publications.html, /gallery.html

3. Referrer-Policy 헤더 누락
- 점검 항목: Referrer-Policy 보안 정책 적용 여부
- 취약점 조치: HTML meta 태그 기반 Referrer 정책 추가 완료
- 처리 방법: 각 HTML 페이지 head 영역에 strict-origin-when-cross-origin 정책 추가
- 적용 페이지: /, /projects.html, /patents.html, /team.html, /publications.html, /gallery.html

4. 이메일 주소 패턴 노출
- 점검 항목: 페이지 내 이메일 주소 직접 노출 여부
- 취약점 조치: 이메일 주소 직접 표기 및 mailto 링크 제거 완료
- 처리 방법: 이메일 텍스트를 [at] 표기 방식으로 변경하여 자동 수집 가능성 완화
- 적용 페이지: /, /team.html
